# Agency Agents Reference

Source: `https://github.com/msitarzewski/agency-agents`

## Use

Use this as a selective role catalog, not a full installation. Assign one or two specialist roles to a bounded task, then let the owning workflow enforce the contract and evidence.

## Recommended roles

- Engineering: Frontend Developer, Backend Architect, Mobile App Builder, AI Engineer, DevOps Automator
- Design: UI Designer, UX Architect, UI Finish-Gate Reviewer
- Quality: Code Reviewer, SRE, security or testing roles relevant to the task
- Product and communication: Product Manager, Technical Writer, UX Researcher

## Routing

Use Jev to rank roles against the current feature boundary, required evidence, and risk. Do not use personality or confidence claims as proof. A specialist role can propose a review, but it cannot override repository standards or human approval.

## Installation boundary

The full roster is large and can create trigger collisions, context bloat, and conflicting personas. Install selected roles only after SkillSpector review and verify compatibility with the target agent host.
